LocalOps is a central cloud native deployment platform that enables developers to offer SaaS, BYOC (Bring your own cloud), On-Prem, Self-hosted versions of their services in minutes. 

No need to write Dockerfiles, Kubernetes helm charts, Terraform/Pulumi scripts or hire DevOps engineers.

In just 30 minutes, provision production grade environments on any cloud, that comes pre-configured with CI/CD, monitoring and everything else, so that you
can simply connect your Github repo and start pushing code to deploy. 

<Info>Before you begin, <a href="https://console.localops.co/signup">create a new account</a> in LocalOps and complete onboarding. This will take just 2 mins to complete.</Info>

This guide provides user manuals, tutorials and concepts to educate your developer teams to start using LocalOps.

Here are some first steps:

<CardGroup cols={2}>
  <Card title="Connect GitHub repository" icon="code" href="/accounts/connect-github">
    Connect your github account and repos to start deploying on every git-push.
  </Card>
    <Card title="Connect your cloud account" icon="cloud" href="/accounts/aws">
    Next step is to connect your cloud account (say AWS).
  </Card>
  <Card title="Launch new environment" icon="container-storage" href="/environment/create">
    Spin up a new environment (say test, staging, production etc.,)
  </Card>
  <Card title="Deploy a new service" icon="rocket" href="/environment/services/create">
    Launch a new service within the environment and start pushing commits to Github to deploy.
  </Card>
</CardGroup>

Once everything is configured, push new commits the configured branch to see automatic deployments triggered.
[Learn more](/environment/services/deploy).
