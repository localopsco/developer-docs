---
title: Compatibility
---

LocalOps supports:

- **Amazon Web Services** - all AWS regions where EKS is supported. AWS has 39+ global regions. Learn more in
  [AWS site](https://aws.amazon.com/about-aws/global-infrastructure/).
- **Google Cloud Platform** - all GCP regions where GKE is available. GCP has 43+ global regions. Learn more in
  [Google Cloud site](https://cloud.google.com/about/locations).

Coming soon:

- Microsoft Azure

See what's planned next on our [public roadmap](https://github.com/orgs/localopsco/projects/9).

Need support for another cloud provider or region? [Contact support](/support) and let us know.
