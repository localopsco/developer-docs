## Cloud providers

LocalOps supports:

- **Amazon Web Services**
- **Google Cloud Platform**

Coming soon:

- Microsoft Azure

## Regions

On AWS, LocalOps supports all AWS cloud regions where EKS is supported.

As on April 2026, AWS has 39 global regions. Learn more in
[AWS site](https://aws.amazon.com/about-aws/global-infrastructure/).

On Google Cloud, LocalOps supports all GCP regions where GKE is available.

GCP has 43 global regions. Learn more in [Google Cloud site](https://cloud.google.com/about/locations).
